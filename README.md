# AI-Takover
It's a game. It's meant to be played with a certain telegraph button, but you can use the F key if you don't have the telegraph. Tap the button for the primary action or press it for 0.3 seconds for the secondary action. Ok here's the premise of the game:
You're an AI, trying to run for president. You are at a debate with you're opponent or something and you have to grab words that are flying by to create a sentence, to make your speech more liked by the audience than your opponent's. Uhm then the next part is where you have to complete a captcha to prove that you aren't a robot, but good luck with that because you *are* a robot 🙄

This game was made at a game jam (Campfire Flagship) and is not finished and likely never will be since the game jam is over :(

[demo here](https://shyaaan.itch.io/ai-takeover). **The demo is a quite old version of the project, and is missing lots of the features and improvements. To get the full game, clone this repo and open it up in Godot.**
